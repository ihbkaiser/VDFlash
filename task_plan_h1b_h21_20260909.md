  max-new-tokens and checkpoint. Report strict losslessness and target parity as

## 2026-09-11 E5 cohort expansion and attention-density revision

### Experiment cards

#### E5-A — Expanded paired Real/Zero cohort

- **Question:** Are the Real-visual-value and Zero-visual-value conditions
  equivalent for draft attention, and does that equivalence extend to
  acceptance length?
- **Hypothesis:** Zeroing visual values should leave attention mass unchanged
  because positions remain in the attention denominator, but it may change
  draft representations and acceptance. Any Real–Zero claim must therefore be
  made separately for attention and acceptance, using paired sample-level
  differences rather than comparing only aggregate means.
- **Protocol:** Use one calibration-valid VDC 3K cohort of at least 20 unique
  test samples. Run the same samples under Full, Retention-25%, and Deleted
  visual contexts, with both `last_instruction` and `all_text` query policies,
  and with Real and Zero visual values. Keep preprocessing, checkpoint,
  decoding and seed fixed. The Real/Zero rows are paired by sample, condition
  and policy.
- **Primary metrics:** sample-level differences in visual/text/instruction
  attention mass and density; acceptance length and strict-losslessness for
  the corresponding MSD runs.
- **Decision rule:** report mean difference, SD, median, paired bootstrap CI and
  exact paired counts. Treat attention as practically equivalent only if the
  CI is inside a predeclared small margin (mass 0.01; density ratio 5%); do not
  infer equivalence from a non-significant test alone.
- **Data note:** the available 3K calibration file is a previous workspace
  calibration artifact, not newly generated training data. Its provenance and
  selected IDs must be recorded with the run.

#### E5-B — Attention density normalization

- **Question:** Is a larger raw attention mass caused only by a condition having
  more eligible visual keys?
- **Hypothesis:** Raw mass can be count-driven. The diagnostic therefore adds
  per-eligible-key attention density and a ratio to the strict-preceding
  uniform-attention density. If a mass difference remains in density, it is
  evidence of a per-token preference, not only token-count scaling.
- **Protocol:** Reuse exactly the E5-A attention rows. For every query policy
  and modality, log the mean number of eligible strict-preceding keys,
  `density = mass / effective_key_count`, and
  `density_ratio = density / uniform_density`. Deleted visual context has zero
  visual eligible keys and is reported as zero visual density with an explicit
  zero-count guard.
- **Primary metrics:** visual density, text density, instruction density and
  their ratios; compare Full vs Reduced within each paired sample.
- **Decision rule:** if Full-to-Reduced mass changes but density does not, the
  observation is primarily explained by key-count dilution; if density also
  changes, the attention allocation changed beyond the count effect. This is
  an attention-mechanism diagnostic, not an accuracy claim.

### E5 expanded results

- Attention: 396/396 summary rows (`33 × 3 × 2 × 2`), 0 error rows; Real and
  Zero are exactly equal for mass, density and density ratio in all 198 pairs.
- Acceptance: 99 Real rows and 99 Zero rows (`33 × 3`), 0 error rows; Real
  minus Zero accepted-prefix mean is `-0.3500` at Full, `-0.1867` at Reduced
  25%, and `0` at Deleted.
- Density: visual density increases from `2.885e-4` to `5.974e-4` for
  `last_instruction` and from `2.561e-4` to `5.215e-4` for `all_text` when
  moving Full to Reduced 25%, while raw visual mass decreases. This rejects a
  count-only explanation for the mass change in this cohort.
- Acceptance is not Real/Zero-equivalent at Full or Reduced: only 1/33 and
  2/33 paired values are exactly equal, respectively; Deleted is 33/33.
